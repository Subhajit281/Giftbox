# Audio playlist

Replace these filenames with the songs you want. Keep the names exactly as written so the experience can find them.

| File | When it plays |
| --- | --- |
| `gift-open.mp3` | When she opens the four-letter gift |
| `proposal.mp3` | When they walk into the proposal room |

MP3, M4A, or OGG all work if you update the matching path in `src/content/playlist.ts`.
You can list extra tracks in that file; the first one that loads will play.
